### BoxReveal

Reveal animation with sliding overlay box.

**Location:** `src/components/reveal-animations.tsx`

**Props:**

```typescript
interface BoxRevealProps {
  children: JSX.Element
  width?: "fit-content" | "100%"   // Default: "fit-content"
  boxColor?: string                 // Default: transparent
  duration?: number                 // Default: 0.5
  delay?: number                    // Default: 0
  once?: boolean                    // Default: true
}
```

**Usage:**

```tsx
import { BoxReveal } from "@/components/reveal-animations"

<BoxReveal delay={2} width="100%">
  <Button>Resume</Button>
</BoxReveal>

<BoxReveal>
  <h2>SKILLS</h2>
</BoxReveal>
```

**How it works:**

1. Content starts hidden with opacity 0 and y offset
2. Content fades in and moves to position
3. Colored box slides from left to right, revealing content
4. Uses `useInView` hook to trigger when element is visible

**Animation variants:**

```typescript
// Content animation
const contentVariants = {
  hidden: { opacity: 0, y: 75 },
  visible: { opacity: 1, y: 0 },
}

// Box slide animation
const boxVariants = {
  hidden: { left: 0 },
  visible: { left: "100%" },
}
```

## Animation patterns

### Framer Motion basics

Components use Framer Motion's declarative API:

```tsx
import { motion } from "framer-motion"

<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.5, delay: 0.2 }}
>
  Content
</motion.div>
```

Used for enter/exit animations:


### useAnimation hook

Programmatic animation control:

```tsx
import { useAnimation } from "framer-motion"

const controls = useAnimation()

useEffect(() => {
  if (condition) {
    controls.start("visible")
  } else {
    controls.start("hidden")
  }
}, [condition])

<motion.div animate={controls} variants={variants} />
```

**Example from codebase:** `src/components/ui/floating-dock.tsx:103`

```tsx
const controls = useAnimation()

useEffect(() => {
  if (showHint) {
    controls.start({
      opacity: [0, 1, 1, 0],
      x: [-50, -50, 50, 50],
      transition: {
        duration: 2,
        repeat: Infinity,
        ease: "easeInOut",
      },
    })
  } else {
    controls.stop()
  }
}, [showHint])
```

### useInView hook

Trigger animations when element enters viewport:

```tsx
import { useInView } from "framer-motion"

const ref = useRef(null)
const isInView = useInView(ref, { once: true })

useEffect(() => {
  if (isInView) {
    controls.start("visible")
  }
}, [isInView])

<div ref={ref}>
  <motion.div animate={controls} />
</div>
```

**Example from codebase:** `src/components/reveal-animations.tsx:67`

Used in BoxReveal:

```tsx
const ref = useRef(null)
const isInView = useInView(ref, { once })

useEffect(() => {
  if (isInView) {
    slideControls.start("visible")
    mainControls.start("visible")
  } else {
    slideControls.start("hidden")
    mainControls.start("hidden")
  }
}, [isInView, mainControls, slideControls])
```

## Common animation configurations

### Transition presets

**Quick fade:**
```typescript
transition={{ duration: 0.3 }}
```

**Smooth slide:**
```typescript
transition={{ duration: 0.5, ease: "easeInOut" }}
```

**Spring:**
```typescript
transition={{ type: "spring", stiffness: 260, damping: 15 }}
```

**Delayed sequence:**
```typescript
transition={{ duration: 0.5, delay: 0.2 * index }}
```

### Easing functions

```typescript
"linear"           // Constant speed
"easeIn"           // Slow start
"easeOut"          // Slow end
"easeInOut"        // Slow start and end
"circIn"           // Circular ease in
"circOut"          // Circular ease out
"backIn"           // Back ease in
"backOut"          // Back ease out
"anticipate"       // Anticipation
```

**Custom easing:**
```typescript
transition={{ ease: [0.17, 0.67, 0.83, 0.67] }}
```

## GSAP animations

Some components use GSAP for complex timeline animations.

**Example from codebase:** `src/components/preloader/index.tsx:53`

```tsx
import gsap from "gsap"

const loadingPercentRef = useRef({ value: 0 })

useEffect(() => {
  const tween = gsap.to(loadingPercentRef.current, {
    value: 100,
    duration: 2.5,
    ease: "slow(0.7,0.7,false)",

    },
  })

```

## Performance considerations

### Will-change optimization

For frequently animated properties:

```css
.animated-element {
  will-change: transform, opacity;
}
```

### GPU acceleration

Use transform properties for better performance:

```tsx
// Good - GPU accelerated
<motion.div
  animate={{ x: 100, scale: 1.2 }}
/>

// Avoid - triggers layout
<motion.div
  animate={{ left: 100, width: 200 }}
/>
```

### Reduce motion

Respect user preferences:

```tsx
import { useReducedMotion } from "framer-motion"

const shouldReduceMotion = useReducedMotion()

<motion.div
  animate={{ opacity: 1 }}
  transition={{ duration: shouldReduceMotion ? 0 : 0.5 }}
/>
```

## Animation best practices

1. **Use appropriate durations**
   - Quick interactions: 0.2-0.3s
   - Standard animations: 0.4-0.6s
   - Dramatic effects: 0.8-1.2s

2. **Stagger animations**
   ```tsx
   {items.map((item, i) => (
     <motion.div
       key={i}
       initial={{ opacity: 0 }}
       animate={{ opacity: 1 }}
       transition={{ delay: i * 0.1 }}
     />
   ))}
   ```

3. **Exit animations**
   ```tsx
   <motion.div
     initial={{ opacity: 0 }}
     animate={{ opacity: 1 }}
     exit={{ opacity: 0 }}
   />
   ```

4. **Limit simultaneous animations**
   - Too many animations can overwhelm users
   - Use sequential reveals for better UX

5. **Test performance**
   - Monitor frame rates
   - Use Chrome DevTools Performance tab
   - Test on lower-end devices
