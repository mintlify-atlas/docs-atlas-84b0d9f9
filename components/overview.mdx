The portfolio is built with a modular component architecture using React, TypeScript, and modern animation libraries. Components are organized into three main categories: UI components, sections, and utility components.

## Component structure

The codebase follows a clear organizational pattern:

```
src/components/
├── ui/              # Reusable UI components
├── sections/        # Page sections (Hero, Skills, Projects, Contact)
├── header/          # Navigation and menu components
├── footer/          # Footer component
└── ...             # Utility components (Particles, Preloader, etc.)
```

## Core technologies

Components leverage several key libraries:

- **React** - Component framework
- **TypeScript** - Type safety and interfaces
- **Framer Motion** - Animations and transitions
- **Radix UI** - Accessible component primitives
- **Tailwind CSS** - Styling with utility classes

## Common patterns

### TypeScript interfaces

Components use TypeScript interfaces for prop typing:

```typescript
interface ButtonProps extends ButtonHTMLAttributes<HTMLButtonElement> {
  variant?: 'default' | 'destructive' | 'outline' | 'secondary' | 'ghost' | 'link'
  size?: 'default' | 'sm' | 'lg' | 'icon'
  asChild?: boolean
}
```

### Forwarded refs

Components use `forwardRef` for DOM access:

```typescript
const Button = forwardRef<HTMLButtonElement, ButtonProps>(
  ({ className, variant, size, ...props }, ref) => {
    // Component implementation
  }
)
```

### Utility function

The `cn()` utility merges Tailwind classes:

```typescript
import { cn } from "@/lib/utils"

<div className={cn("base-classes", className)} />
```

## Animation approach

Components use Framer Motion for declarative animations:

```typescript
<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.5 }}
>
  Content
</motion.div>
```

## Context providers

Several components use React Context for state management:

- `PreloaderContext` - Loading state
- `ModalContext` - Modal open/close state
- `TooltipProvider` - Tooltip configuration
