# Introduction

Welcome to the 3D Interactive Portfolio documentation! This project helps you create a visually stunning and interactive portfolio website featuring 3D animations, smooth scrolling, and engaging user experiences.

## What is 3D Interactive Portfolio?

This is a modern portfolio template built with Next.js 14 that showcases your skills, projects, and experience through:

- **3D Interactive Keyboard**: A custom Spline-powered keyboard where each keycap represents a skill with hover interactions
- **Smooth Animations**: GSAP and Framer Motion powered animations for scroll, hover, and element reveals
- **Space-Themed Design**: Particle effects and cosmic backgrounds for a futuristic aesthetic
- **Responsive Layout**: Optimized for desktop and mobile devices
- **Real-time Features**: Live cursor tracking with Socket.io integration

## Key features

### 3D interactive animations

The portfolio features a custom-made interactive keyboard built with Spline. Each keycap represents a skill and reveals titles and descriptions on hover for an immersive experience.

### Smooth interactions

Powered by GSAP and Framer Motion, the portfolio delivers buttery-smooth animations on scroll, hover, and element reveals. Creative motion designs enhance storytelling and keep users engaged.

### Real-time collaboration

Socket.io integration enables live cursor tracking, allowing visitors to see other users exploring your portfolio in real-time.

### Modern tech stack

Built with cutting-edge technologies:

- **Next.js 14** with App Router
- **React 18** for UI components
- **Tailwind CSS** for styling
- **Shadcn UI** and **Aceternity UI** for beautiful components
- **GSAP** and **Framer Motion** for animations
- **Spline** for 3D graphics
- **Resend** for contact form emails
