# Quickstart

Get your stunning 3D interactive portfolio up and running in just a few minutes.

## Prerequisites

Before you begin, ensure you have:

- **Node.js** 20.x or higher installed
- **npm** or **yarn** package manager
- A **Resend** account (free tier available) for contact form functionality
- Basic knowledge of React and Next.js

<Note>
  This project uses Next.js 14 with the App Router. Make sure you're familiar with the basics of Next.js before customizing.
</Note>

## Quick setup

<Steps>
  <Step title="Clone the repository">
    Clone the repository to your local machine:

    <CodeGroup>
      ```bash npm
      git clone https://github.com/Abhiz2411/3D-interactive-portfolio.git
      cd 3D-interactive-portfolio
      ```

      ```bash yarn
      git clone https://github.com/Abhiz2411/3D-interactive-portfolio.git
      cd 3D-interactive-portfolio
      ```
    </CodeGroup>
  </Step>

  <Step title="Install dependencies">
    Install all required packages:

    <CodeGroup>
      ```bash npm
      npm install
      ```

      ```bash yarn
      yarn install
      ```
    </CodeGroup>

    This will install all dependencies including:
    - Next.js, React, and Tailwind CSS
    - GSAP and Framer Motion for animations
    - Spline Runtime for 3D graphics
    - Resend for email functionality
    - Socket.io for real-time features
  </Step>

  <Step title="Configure environment variables">
    Create a `.env.local` file in the root directory:

    ```bash
    touch .env.local
    ```

    Add your Resend API key:

    ```bash .env.local
    RESEND_API_KEY=your_resend_api_key_here
    ```

    <Tip>
      Sign up for a free Resend account at [resend.com](https://resend.com) to get your API key. The free tier includes 100 emails per day.
    </Tip>
  </Step>

  <Step title="Start the development server">
    Launch the development server:

    <CodeGroup>
      ```bash npm
      npm run dev
      ```

      ```bash yarn
      yarn dev
      ```
    </CodeGroup>

    Open your browser and navigate to:

    ```
    http://localhost:3000
    ```
  </Step>
</Steps>

## Customize your portfolio

Now that your portfolio is running, customize it with your own information:

### Update site configuration

Edit the configuration file at `src/data/config.ts`:

```typescript src/data/config.ts
const config = {
  title: "Your Name | Your Title",
  description: {
    long: "Your detailed description here...",
    short: "Your short bio here...",
  },
  keywords: [
    "your-name",
    "portfolio",
    "web development",
    // Add your keywords
  ],
  author: "Your Name",
  email: "your.email@example.com",
  site: "https://yoursite.com",
  social: {
    twitter: "https://x.com/yourhandle",
    linkedin: "https://www.linkedin.com/in/yourprofile",
    github: "https://github.com/yourusername",
    // Add more social links
  },
};
export { config };
```
